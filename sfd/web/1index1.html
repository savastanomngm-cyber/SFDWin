HOW TO READ THE SURFACE
· X = strike · Y = days-to-expiry · Z/color = implied vol.
· Mountains (high IV) = vol being BOUGHT → dealers fade → price tends to REJECT.
· Valleys (low IV) = vol SOLD → little hedging resistance → price ACCELERATES through.
· Amber line = ATM ridge (spot). Blue line = 0DTE front edge (the intraday F1 car).
· Red ◆ = detected spikes (reject zones) · Green ● = pockets (acceleration zones).
· TOP view = clean heatmap read · ISO = shape · 2D = flat map with exact strikes.
